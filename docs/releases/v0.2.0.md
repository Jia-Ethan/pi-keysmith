# v0.2.0

First public release of `pi-keysmith`, adding the machine-readable contract
Keysmith Switch uses.

## Highlights

- `--json` emits one `pi-keysmith.envelope.v1` object on stdout for status,
  deploy, uninstall, and recover. Contract: `docs/json-contract.md`.
- Preview/confirm split with `--expected-preview-token`; the token binds the
  directory, state, `SYSTEM.md`, manifest, backups, and residue.
- Directory lock for confirmed writes (exit 5 when busy).
- `--recover` no longer rolls back a completed deploy interrupted during
  cleanup, and now cleans orphan cleanup markers and temp files.
- Uninstall checks the previous-manifest backup fingerprint.
